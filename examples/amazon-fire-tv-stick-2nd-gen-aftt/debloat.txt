# Amazon Fire TV Stick 2nd gen (AFTT, codename tank), Fire OS 5.2.9.5 (688805020), Android 5.1.1 (SDK 22), 1 GB RAM, India
# FIRE OS: com.amazon.tv.launcher keeps Home and launcher/ needs Android 8; firehome/ (minSdk 22) covers Home instead.
#
# Apply:   HIDE=1 TV_HOST=<stick ip> tools/disable.sh examples/amazon-fire-tv-stick-2nd-gen-aftt/debloat.txt
# Undo:    HIDE=1 TV_HOST=<stick ip> tools/restore.sh examples/amazon-fire-tv-stick-2nd-gen-aftt/debloat.txt com.amazon.tv.launcher
# HIDE=1 matters: Fire OS 5.2.9.5 answers every pm disable-user from the shell, system or third-party package, with
# "SecurityException: Permission Denial: attempt to change component state". `pm hide` works for third-party apps
# ("new hidden state: true") and `pm unhide` undoes it, but for every system package below it answers
# "new hidden state: false" and changes nothing. So on this firmware only the batch-3 apps the owner installed
# (Netflix, JioHotstar, SonyLIV, Zee5, Jio, the two com.kyy apps) were actually hidden; Prime Video is a system app
# and stays. The system entries are kept so the list is complete for firmware that allows more; re-running is harmless.
# Nothing is uninstalled: this pm has no install-existing, so a system package uninstalled for user 0 comes back only
# with a factory reset, and setup after a reset needs a physical remote.
# What did help on top: animation scales at 0.5 (settings put global window_animation_scale / transition_animation_scale
# / animator_duration_scale 0.5; restore.sh puts back the recorded values), and firehome/ so Amazon's home with its
# full-screen ads and sponsored rows is never on screen. MemAvailable went from ~138 MB to ~167 MB of 895 MB.
# Comment out any line you want to keep.
# ADB on Fire OS 5: Settings > My Fire TV > Developer options > ADB debugging. Port 5555, "Allow USB debugging?" once.
# This adbd takes one connection at a time: close tools/remote.py before running anything else with tools/tv.py.
#
# NO REMOTE? This stick was set up without one, driven through tools/firetv.py (the Fire TV phone app's API on
# ports 8009/8080). So kept on purpose: com.amazon.dialservice, com.amazon.tv.turnstile (DIAL launches),
# com.amazon.firerestapiframework, com.amazon.storm.lightning.services and .tutorial, com.amazon.whisperlink.core.android,
# com.amazon.whisperplay.*, com.amazon.ssdpservice, com.amazon.communication.discovery, com.amazon.awvflingreceiver,
# and the remote/Bluetooth side (autopairservice, bluetoothinternals, device.blepa, device.bluetoothpa,
# fireinputdevices, tv.keypolicymanager, device.rdmapplication: remote battery and firmware) for a replacement remote.
# Also kept: com.amazon.tv.launcher, settings (tv.settings.v2, tv.settings.core, device.settings), com.amazon.tv.ime,
# com.amazon.venezia (Appstore), account sign-in (com.amazon.imp, com.amazon.dcp, identity.*, com.amazon.aca),
# OTA updates, CEC (tv.devicecontrol), webview, screensaver, profile picker, TTS and accessibility.
# The owner watches YouTube (com.amazon.firetv.youtube), so every other streaming app is in batch 3.
#
# Applied in three runs (batch 1, then 2 and 3), checked with screenshots, YouTube launching and the remote API
# answering after each. disable.sh records the state of names a list gains before switching them off.
